# Override User Avatars

Override avatars for multiple users in Revenge, Vendetta, and Kettu clients. Each user can have a primary image and an optional fallback image, managed from a list in the plugin settings.

**Status:** Vibe coded without remorse, build-tested locally, and awaiting phone and iPad field testing.

## How to install

Paste this link into the Install Plugin section of the Revenge client:

https://stirlo.github.io/Override-User-Avatar-Plugin/Override-User-Avatars

Open the plugin settings, enter a user ID and direct primary image URL, optionally enter a fallback URL, then tap **Add and store locally**. Tap an existing user row to remove that override.

The plugin downloads PNG, JPEG, WebP, and GIF images up to 750 KB and stores them as data URIs in Kettu's on-device plugin data. Source URLs are not retained after a successful import, and avatar rendering does not require another network request. The images are not encrypted. Locally stored images remain on that device and may be removed when Kettu or its app data is reinstalled or cleared.

Existing remote URL entries remain compatible. Remove and re-add them to import their images into local storage.

The fallback image is selected only when the primary field is empty. It is not an automatic retry when an image fails to decode. The settings form requires a primary image when adding an entry.

The install URL points to a polymanifest deployment. The client reads the generated `manifest.json`, loads `index.js`, and checks the bundle against its generated SHA-256 hash.

## Known issues

The plugin does not change profile pictures in notifications.
